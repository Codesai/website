# CWS-TEST-001 — Validación reproducible del sitio                                                                                        
                                                                                                                                            
  ## Resumen                                                                                                                                
                                                                                                                                            
  Crear make test como único comando local, preparado para poder reutilizarse posteriormente en un GitHub Action ejecutado con cada push a  
  main. En esta tarea no se añadirá CI.                                                                                                     
                                                                                                                                            
  ## Cambios                                                                                                                                
                                                                                                                                            
  - Añadir html-proofer 5.2.1 al Gemfile y bloquearlo en Gemfile.lock.                                                                      
  - Crear una prueba que:                                                                                                                   
      - Se ejecute mediante Docker.                                                                                                         
      - Construya una copia temporal fiel a producción.                                                                                     
      - Copie los posts españoles para generar también la versión inglesa, sin modificar el repositorio.                                    
      - Verifique las páginas principales y posts ES/EN.                                                                                    
      - Compruebe enlaces, anchors, imágenes, scripts y estilos internos.                                                                   
      - Considere internos codesai.com y www.codesai.com.                                                                                   
      - Reconozca las rutas históricas cubiertas por netlify.toml.                                                                          
      - Compruebe respuestas 200 para / y /en/.                                                                                             
      - Compruebe respuestas 404 y el contenido .error-404 para rutas inexistentes ES/EN.                                                   
      - Elimine siempre procesos y archivos temporales.                                                                                     
                                                                                                                                            
  - Añadir make test y documentarlo en README.md y AGENTS.md.                                                                               
  - Marcar CWS-TEST-001 como DONE únicamente cuando la suite pase.                                                                          
                                                                                                                                            
  ## Validación                                                                                                                             
                                                                                                                                            
  - Ejecutar make test desde un entorno limpio.                                                                                             
  - Confirmar el build completo de ES/EN y la generación equivalente de posts.                                                              
  - Corregir enlaces o recursos internos realmente rotos; no ocultarlos con excepciones.                                                    
  - No consultar enlaces externos.                                                                                                          
  - Confirmar mediante una referencia inválida temporal que la suite falla correctamente.                                                   
  - Verificar que la ejecución no deja cambios ni procesos en el repositorio.                                                               
                                                                                                                                            
  ## Decisiones fijadas                                                                                                                     
                                                                                                                                            
  - El proyecto trabaja directamente sobre main; no se diseñará nada alrededor de pull requests.                                            
  - La integración con GitHub Actions queda pendiente.                                                                                      
  - Un futuro Action reutilizará make test en cada push a main.                                                                             
  - Esta tarea cubre build, enlaces, recursos y 404. Las interacciones pertenecen a CWS-TOOL-007.
