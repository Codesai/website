# CWS-TOOL-008 — Añadir regresión visual

## Resumen

Se incorporó una red de regresión visual reproducible con Playwright para detectar cambios de apariencia en las páginas principales del sitio antes de abordar las optimizaciones posteriores.

## Trabajo realizado

- Se añadió un proyecto Playwright específico para tableta, junto a los proyectos existentes de escritorio y móvil.
- Se creó `tests/e2e/visual.spec.js` con 18 rutas representativas en español e inglés.
- Cada caso espera a que terminen la red, las fuentes y las imágenes antes de comparar una captura de página completa.
- Se desactivaron animaciones y cursor, y se fijó un máximo de diferencia de píxeles del 0,1 %.
- Se estabilizó el orden de las tarjetas del equipo, cuyo contenido podía variar entre builds.
- Se integraron la ejecución visual y la actualización explícita de baselines en los comandos del proyecto.
- Se aprobaron 108 imágenes de referencia: 18 páginas × 2 idiomas × 3 viewports.

## Validación realizada

- Se ejecutaron las comparaciones en Chromium para escritorio, Pixel 5 y tableta de 768 × 1024.
- Se confirmó la cobertura de home, servicios, newsletter, 404 y las páginas de cursos en ES/EN.
- Se comprobó que las capturas solo se actualizan mediante el comando dedicado y que las diferencias hacen fallar la suite.
- La regresión visual quedó integrada en `make test` junto a la caracterización funcional.

## Resultado

- Tarea completada en el commit `700775f` (`test: add visual regression coverage`).
- Los cambios visuales aprobados posteriormente en la fase 2 quedaron registrados de forma separada en `6c590bb`.
