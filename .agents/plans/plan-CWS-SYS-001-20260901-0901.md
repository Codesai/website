# CWS-SYS-001 — Migrar la imagen a Debian Trixie

## Resumen

Se migró la imagen de desarrollo y validación desde Debian 12 Bookworm a Debian 13 Trixie, manteniendo Ruby 4.0.6 y verificando explícitamente la compatibilidad multiplataforma.

## Trabajo realizado

- Se cambió la imagen base a `ruby:4.0.6-trixie`.
- Se mantuvo la instalación de Node.js, npm, SVGO, pngquant y las dependencias del navegador sobre Trixie.
- Se añadieron al lockfile la plataforma `aarch64-linux` y las variantes nativas necesarias para ARM64.
- Se resolvieron Nokogiri, Sass Embedded, Google Protobuf, FFI e Image Optim Pack para ambas arquitecturas.
- Se actualizó `CWS-SYS-001` a `DONE` tras validar AMD64 y ARM64.

## Validación realizada

- Se construyó y probó la imagen AMD64 mediante la suite completa `make test`.
- Dentro de la imagen se verificaron Ruby 4.0.6, Node 24.20.0, npm 11.19.0, SVGO 4.1.0, pngquant 2.18.0 y Playwright 1.62.1.
- Se realizó una compilación completa `linux/arm64` mediante Buildx y emulación QEMU temporal.
- La compilación ARM64 instaló correctamente las gems nativas, las bibliotecas de Trixie y Chromium 151 para ARM64.
- El emulador ARM64 temporal se retiró una vez concluida la comprobación.

## Resultado

- Tarea completada en el commit `f3be2d8` (`build: migrate the image to Debian Trixie`).
- La imagen queda validada sobre Debian 13 para AMD64 y ARM64 sin perder las herramientas de build ni la suite de navegador.
