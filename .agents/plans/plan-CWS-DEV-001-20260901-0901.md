# CWS-DEV-001 — Ejecutar Jekyll mediante Bundler

## Resumen

Se corrigió el arranque local para que Jekyll utilice siempre las versiones bloqueadas en `Gemfile.lock`, evitando diferencias entre el entorno de desarrollo y las validaciones del proyecto.

## Trabajo realizado

- Se endureció `scripts/development_build.sh` con `set -euo pipefail`.
- Se sustituyó la invocación directa de Jekyll por `bundle exec jekyll serve`.
- Se conservaron el acceso desde el host, el sondeo de cambios y la combinación de la configuración general y local.
- Se actualizó `CWS-DEV-001` a `DONE` después de comprobar el arranque.

## Validación realizada

- Se construyó y arrancó el sitio dentro de un contenedor temporal.
- Se comprobó que `http://localhost:4000` respondía con estado HTTP 200.
- Se confirmó que el proceso utilizaba las dependencias gestionadas por Bundler.

## Resultado

- Tarea completada en el commit `f1d1e7d` (`dev: run Jekyll through Bundler`).
- El servidor local queda alineado con las versiones reproducibles del proyecto.
