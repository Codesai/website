# CWS-CSS-001 — Migración al sistema de módulos Sass

Se sustituyeron los 16 `@import` de `sass/main.scss` por `@use`, conservando su orden. El módulo `base` emite primero las reglas globales originales para mantener la cascada.

Las variables se trasladaron a `_sass/_variables.scss` y `pxToRem` a `_sass/_functions.scss`. `_sass/_shared.scss` expone ambas dependencias mediante `@forward`, sin emitir CSS. Cada componente declara su dependencia con `@use "shared" as *`. La hoja independiente `online-open-space.scss` reutiliza únicamente la función y conserva sus variables propias.

## Verificación

- Antes de editar se compilaron las dos entradas con `Sass.compile_string`, usando `sass-embedded` del contenedor de desarrollo y las rutas de carga `/app/sass` y `/app/_sass`, retirando únicamente el front matter de Jekyll.
- Después se repitió la compilación con las mismas opciones: el CSS de ambas entradas resultó idéntico byte a byte, sin mapas de fuentes ni avisos de `import`.
- Se reinició el servicio local: compilación ES/EN correcta, servidor en `localhost:4000` con HTTP 200 y sin avisos de `import`.
- `make test` completo: compilación ES/EN, HTML-Proofer, comprobaciones HTTP 404 y Playwright correctos; comparaciones visuales en escritorio, móvil y tablet sin actualizar referencias. El registro completo no contiene avisos Sass de `import`.
