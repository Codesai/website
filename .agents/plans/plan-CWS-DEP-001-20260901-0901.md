# CWS-DEP-001 — Actualizar HTML Proofer y Async

## Resumen

Se actualizaron las dependencias Ruby de validación para eliminar la versión obsoleta de HTML Proofer y la fijación transitoria de Async, manteniendo reproducible el build ES/EN.

## Trabajo realizado

- Se actualizó `html-proofer` de 5.2.1 a 5.2.2 en `Gemfile` y `Gemfile.lock`.
- Se retiró la dependencia directa temporal de Async del `Gemfile`.
- Bundler resolvió y bloqueó `async` 2.45.1 como dependencia transitiva compatible.
- Se comprobó que el conjunto de gems bloqueadas estaba actualizado.
- Se marcó `CWS-DEP-001` como `DONE` tras superar la suite completa.

## Validación realizada

- `bundle outdated --strict` no encontró actualizaciones pendientes dentro de las restricciones.
- `make test` completó el build de ambos idiomas y la comprobación de 746 enlaces sobre 456 archivos.
- Desapareció el aviso de `Scheduler#fiber_interrupt` asociado a la versión anterior; únicamente permaneció el aviso experimental de Ruby sobre `IO::Buffer`.
- Las pruebas funcionales y visuales siguieron pasando con la nueva resolución de gems.

## Resultado

- Tarea completada en el commit `e244540` (`build: update HTML Proofer and Async`).
- La validación de enlaces queda sobre versiones actuales y compatibles con Ruby 4.
